# Vintage Story Presence

An extensible Vintage Story client-side mod to show your in-game activity as your Discord status with plenty of customization!

The intent with this mod was to simplify both the user experience and developer experience. When loading in, config values are already set and look great, but if you'd like to make it your own, there are a lot of options :D

    <li>Advanced activity tokens</li>
    <li>Easily extensible command registrar</li>
  </ul>

### Requirements
- **Discord stable 543408+**
- **Vintage Story 1.22.2+**
- (optional) **[ConfigLib](https://mods.vintagestory.at/configlib) 1.12.0+**

> This mod uses the [DiscordRPC-NativeAOT](https://www.nuget.org/packages/DiscordRPC-NativeAOT) NuGet package, which performs all crossplatform compatability layering. If there are any platform compatability problems, please create an issue [here](https://github.com/samse1337/DiscordRPC-NativeAOT/issues?q=sort%3Aupdated-desc%20is%3Aissue%20is%3Aopen%20).
